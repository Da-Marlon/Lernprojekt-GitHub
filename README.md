# Lernprojekt-GitHub

## Dieses Projekt

Dieses Projekt dient dazu, dass ich lerne, wie man Issues, Milestones und Projects auf GitHub nutzt.

## Aufbau

Das Repository besteht aus drei Ordnern:

```
Lernprojekt-GitHub/
├── README.md
├── docs/   Dokumentation
├── src/    Code
└── img/    Bilder
```

## Workflow

1. Issue erstellen und auf dem Board in «To Do» ziehen.
2. Sobald daran gearbeitet wird, das Issue nach «In Progress» verschieben.
3. Fortschritte als Kommentar im Issue festhalten.
4. Wenn die Aufgabe fertig ist, das Issue nach «Review» verschieben und prüfen.
5. Issue mit einem Abschlusskommentar schliessen und nach «Done» verschieben.

Alle vorbereitenden Aufgaben gehören zum Milestone «Projektsetup».
